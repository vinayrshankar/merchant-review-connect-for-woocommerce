# Changelog

## 1.1.0 - 2026-09-07

- Rebuilt the plugin around a new service-oriented architecture.
- Moved source code to a domain-oriented `src/` tree.
- Adopted the `VinayShankar\MerchantReviewConnect` namespace.
- Replaced singleton/static service patterns with explicit dependency injection.
- Replaced the standalone admin page with a native WooCommerce settings tab.
- Replaced the shared settings-array option with individual WordPress options.
- Moved Google integration runtime logic into dedicated JavaScript assets.
- Added independent-implementation and architecture documentation.
- Preserved Google Customer Reviews, product GTIN, delivery-estimate, store-widget, HPOS, and checkout-block capabilities.

## 1.0.0 - 2026-09-07

- Initial public release.
