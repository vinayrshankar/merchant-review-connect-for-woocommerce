# Changelog

All notable changes to Merchant Review Connect for WooCommerce are documented here.

## 1.0.0 - 2026-09-07

- Initial public release.
- Added Google Customer Reviews survey opt-in integration.
- Added estimated-delivery-date calculation and order-meta override.
- Added GTIN lookup and check-digit validation.
- Added optional Google store widget integration.
- Added HPOS and Cart/Checkout Blocks compatibility declarations.
- Added GitHub-ready project documentation.
