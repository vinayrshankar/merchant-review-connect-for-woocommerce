An independently implemented WooCommerce integration for Google Customer Reviews and the Google store widget.

== Description ==

Merchant Review Connect for WooCommerce connects authorized WooCommerce order-confirmation pages to Google Customer Reviews without a license key, telemetry service, external account broker, or bundled updater.

Features include Google Customer Reviews opt-in, validated product GTIN submission, configurable delivery-date estimation, the optional Google store widget, HPOS compatibility, and Cart/Checkout Blocks compatibility declarations.

Author: Vinay Shankar
Website: https://tfaworld.org/

== Installation ==

1. Upload the plugin ZIP through WordPress Plugins > Add New Plugin > Upload Plugin.
2. Activate Merchant Review Connect for WooCommerce.
3. Open WooCommerce > Settings > Merchant Reviews.
4. Enter your Merchant Center ID.
5. Configure the survey, delivery estimate, product identifiers, and optional store widget.
